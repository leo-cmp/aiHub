# Frontend Guidelines

- Siga os padroes visuais e componentes existentes antes de criar novos.
- O framework/lib de UI e suas convencoes estao em `.ai/guidelines/stacks/<stack>.md`.
- Interfaces operacionais devem ser densas, claras e escaneaveis.
- O idioma da UI esta definido em `.ai/project.md`; nao deixe labels, botoes, titulos de modal ou headings em idioma diferente do definido.
- Garanta estados vazio, carregando, erro, sucesso e responsividade.
- Se mudanca visual nao aparecer, pode ser necessario build/dev server.
