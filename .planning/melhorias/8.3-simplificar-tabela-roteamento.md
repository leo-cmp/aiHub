# 8.3 — Simplificar Tabela de Roteamento

**Categoria:** Desacoplamento de Agentes | **Prioridade:** 🟡 Alta | **Esforço:** S
**Fonte:** DEEPSEEK

## Objetivo

Simplificar a tabela de roteamento de 3 colunas (Agente | Demanda | Cargo) para 2 colunas (Demanda | Cargo). Já implementado junto com o item 8.1 (remover identificação de agente). Este arquivo documenta o resultado final.

## Especificação

### Tabela final (2 colunas)

```markdown
## Roteamento Atual

| Demanda | Cargo |
|---|---|
| `.ai/project.md` nao existe, ou humano pede para configurar/revisar o projeto | `project-planner` |
| entrada inicial, roteamento, recomendacao de agente/modelo | `model-router` |
| requisitos, fases, planos, tasks, issues, decisao de escopo | `technical-lead` |
| descoberta de produto, regra ambigua, criterio de negocio | `product-analyst` |
| implementacao backend + frontend | `fullstack-engineer` |
| implementacao backend/API/jobs/services | `backend-engineer` |
| implementacao UI/frontend | `frontend-engineer` |
| review, testes, validacao, PRs, release | `qa-release-engineer` |
| schema, migrations, queries, indices, performance SQL | `database-engineer` |
```

### Seção de Flexibilidade

```markdown
## Flexibilidade de Agentes e Cargos

A divisão de cargos orienta o foco e comportamento que a IA deve adotar durante a demanda.
Qualquer agente pode assumir qualquer cargo — a escolha depende da necessidade, não do modelo.
```
