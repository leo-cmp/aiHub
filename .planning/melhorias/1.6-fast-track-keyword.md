# 1.6 — Fast-Track por Keyword

**Categoria:** Tokenomia e Contexto | **Prioridade:** 🟢 Média | **Esforço:** S
**Fonte:** ANALISE_FREE.md

## Objetivo

Refinar o fast-track L1 com detecção por keyword. Se a demanda começar com `add`/`rename`/`remove`/`fix typo` e afetar 1 arquivo, pulo automático.

## Especificação

No bloco `## Fast-Track (L1 — Trivial)` (criado no item 1.2), adicionar gatilho por keyword:

```markdown
## Fast-Track (L1 — Trivial)

Se a demanda atender TODOS os critérios abaixo, pule o fluxo normal:

**Gatilhos por keyword (dispensa análise):**
- "adiciona campo X na tabela Y"
- "renomeia X para Y"
- "remove X"
- "corrige typo em X"
- "muda tipo de X para Y"

**Critérios de elegibilidade:**
- 1 arquivo afetado (ou 1 migration + 1 model do mesmo domínio)
- Sem criação de schema novo (tabela/nova entidade)
- Sem regra de negócio envolvida
- Sem alteração de interface pública (API/rota)

**Fluxo fast-track:**
1. Confirme o arquivo alvo existe
2. Faça a alteração
3. Rode lint/teste relacionado
4. Registre no Log de Evidencias
5. Reporte concluído
```

## Arquivos Afetados

- `src/AGENTS.md`: expandir bloco Fast-Track com keywords

## Critérios de Aceite

- [ ] Fast-track lista 5 keywords de gatilho
- [ ] Keywords são em português (idioma do AGENTS.md)
- [ ] Fluxo permanece com 5 passos
- [ ] Escape hatch mantido
