# 11.2 — `npx aihub install` (v0.5+)

**Categoria:** Distribuição e Instalação | **Prioridade:** 🟡 Alta | **Esforço:** L
**Fonte:** DEEPSEEK

## Objetivo

Empacotar o aiHub como pacote npm para instalação via `npx aihub install`. Sem clonar repo, sem git submodule. Instala tudo (skills são minúsculas, lazy loading resolve). Docs e exemplos não vão no pacote.

## Fase Separada (v0.5+)

Este item é planejamento para versão futura. Não é para implementar agora. A dependência é: item 11.3 (src/) + item 11.1 (install.sh) concluídos primeiro.

## Especificação

### Estrutura do pacote

```
aihub/
├── package.json          ← nome: "aihub", bin: { "aihub": "scripts/install.sh" }
├── src/                  ← mesmo conteúdo atual
├── scripts/
│   └── install.sh        ← mesmo script, invocado via npx
├── README.md
└── VERSION
```

### package.json

```json
{
  "name": "aihub",
  "version": "0.4.0",
  "description": "Central portátil de configuração e diretrizes para agentes de IA",
  "bin": {
    "aihub": "scripts/install.sh"
  },
  "files": [
    "src/",
    "scripts/install.sh"
  ],
  "keywords": ["ai", "agent", "orchestrator", "context", "llm"],
  "license": "MIT"
}
```

### Uso

```bash
# Instalar em projeto existente
npx aihub install

# Ou se instalado globalmente
npm i -g aihub
aihub install
```

### O que NÃO vai no pacote

| Item | Motivo |
|------|--------|
| `docs/` | Documentação de desenvolvimento, não necessária no projeto alvo |
| `examples/` | Exemplos para devs do aiHub, não para usuários finais |
| `.github/` | CI/CD do aiHub |
| `.planning/` | Planejamento interno |
| `.threadbridge/` | Memória local do dev |
| `.claude/`, `.junie/`, `.obsidian/` | Config local |
| `ANALISE_*.md`, `PLANO_*.md` | Artefatos de análise |
| `Makefile` | Já removido (item 11.1) |

### Publicação

```bash
npm publish
```
