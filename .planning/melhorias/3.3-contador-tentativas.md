# 3.3 — Contador de Tentativas na Task

**Categoria:** Memória e Handoff | **Prioridade:** 🟡 Alta | **Esforço:** S
**Fonte:** DEEPSEEK

> Nota: Este item complementa o circuit breaker 6.2 (máx 3 tentativas por critério). Enquanto 6.2 define o limite no `execution.md`, este item (3.3) integra o contador no template de task.

## Objetivo

Adicionar contador de tentativas no template `task.md` para rastrear quantas vezes cada critério de aceite foi tentado. Essencial para handoff — o próximo agente sabe que o critério já falhou N vezes.

## Especificação

### Mudança no template task.md

Adicionar após a seção `## Erros e Correções`:

```markdown
## Contador de Tentativas

| Criterio | Tentativas | Ultima tentativa | Status |
|----------|------------|------------------|--------|
| Criterio 1 | 0 | — | pendente |
| Criterio 2 | 0 | — | pendente |

- Maximo 3 tentativas por criterio.
- Na 3a falha consecutiva: marcar como BLOQUEADO, parar, informar usuario.
- No handoff, o proximo agente le esta tabela e sabe o historico.
```

### Integração com execution.md

Já coberto pelo item 6.2. Este item só adiciona o rastreamento no template.

## Arquivos Afetados

- `src/.ai/templates/task.md`: adicionar `## Contador de Tentativas`
- `src/.ai/templates/task-short.md`: não adicionar (tarefas L1 são triviais, sem múltiplos critérios)

## Critérios de Aceite

- [ ] `task.md` contém tabela de contador de tentativas
- [ ] Tabela referencia máximo de 3 tentativas
- [ ] Tabela tem colunas: Critério, Tentativas, Última tentativa, Status
- [ ] `task-short.md` NÃO tem contador (desnecessário para L1)
