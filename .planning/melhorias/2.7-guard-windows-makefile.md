# 2.7 — Guard Windows no install.sh

**Categoria:** Robustez do Sistema de Regras | **Prioridade:** ⚪ Baixa | **Esforço:** S
**Fonte:** ANALISE_FREE.md

> Nota: Originalmente "Guard Windows no Makefile". Com a remoção do Makefile (item 11.1), o guard vai no `install.sh`.

## Objetivo

Detectar Windows sem WSL no `install.sh` e informar o usuário com mensagem clara, em vez de quebrar silenciosamente com erro confuso de bash.

## Situação Atual

O Makefile (a ser removido) e o futuro `install.sh` usam bash e symlinks — que não funcionam em Windows puro (sem WSL). O público-alvo (dev PHP/Laravel/JS) normalmente usa Unix, mas é bom ter uma mensagem clara para a exceção.

## Especificação

Adicionar no início de `scripts/install.sh`:

```bash
#!/usr/bin/env bash
set -euo pipefail

# Guard: Windows sem WSL
case "$(uname -s 2>/dev/null || echo 'Unknown')" in
    MINGW*|MSYS*|CYGWIN*)
        echo "AVISO: Ambiente Windows detectado sem WSL."
        echo "O aiHub requer ambiente Unix (Linux, macOS ou Windows com WSL)."
        echo "Alternativas:"
        echo "  1. Use WSL (recomendado): https://learn.microsoft.com/windows/wsl/install"
        echo "  2. Instale manualmente: copie src/AGENTS.md para a raiz, src/.ai/ para .ai/, etc."
        echo "  3. Use Git Bash e substitua symlinks por cópias (menos recomendado)"
        exit 1
        ;;
esac
```

## Arquivos Afetados

- `scripts/install.sh`: adicionar guard no início

## Critérios de Aceite

- [ ] `install.sh` detecta Windows (MINGW/MSYS/CYGWIN) e exibe mensagem
- [ ] Mensagem explica alternativas (WSL, manual, Git Bash)
- [ ] Script faz exit 1 em Windows sem WSL
- [ ] Unix (Linux/macOS) não é afetado
