# 7.1 — Diretório examples/

**Categoria:** Documentação e Onboarding | **Prioridade:** 🟡 Alta | **Esforço:** M
**Fonte:** ANALISE_FREE.md

## Objetivo

Criar diretório `examples/` com arquivos preenchidos mostrando o padrão esperado. Quem clona o aiHub vê exemplos reais em 2 minutos, em vez de templates vazios.

## Especificação

### Arquivos a criar

```
src/examples/
├── project.md          ← .ai/project.md preenchido (projeto fictício "E-Commerce")
├── stack.md            ← .ai/stack.md preenchido (CI4 + Tailwind + MySQL)
├── plan.md             ← .planning/PLAN_V1/plan.md preenchido (fase "Checkout")
```

```markdown
## Regras de Negócio
```

**`business-rule.md` (exemplo):**
```markdown
# Regras de Negócio — Financeiro

## Precisão Monetária
- Todos os valores monetários usam `DECIMAL(15,2)`.
- Nunca use `FLOAT` ou `DOUBLE` para dinheiro.

## Imutabilidade
- Transações financeiras NUNCA são alteradas após confirmação.
- Estornos criam nova transação (nunca alteram a original).

## Auditoria
- Toda transação registra: `created_at`, `created_by`, `ip_address`.
```
