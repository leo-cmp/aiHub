# 7.4 — Verificação Antes de Criar Artefatos

**Categoria:** Documentação e Onboarding | **Prioridade:** 🟢 Média | **Esforço:** S
**Fonte:** DEEPSEEK

## Objetivo

Adicionar instrução para verificar se um artefato (model, migration, controller) já existe antes de executar `make:*` ou equivalente. O flag `--no-interaction` do Laravel suprime avisos de sobrescrita.

## Situação Atual

`laravel.md:6`: `php artisan make:* --no-interaction`

Se o LLM gerar `php artisan make:model User --no-interaction` e `User` já existir, pode sobrescrever silenciosamente.

## Especificação

### Mudança em laravel.md

```markdown
# Antes:
- Crie arquivos Laravel com `php artisan make:* --no-interaction` quando aplicavel.

# Depois:
- Crie arquivos Laravel com `php artisan make:* --no-interaction` quando aplicavel.
- **Antes de cada `make:*`:** verifique se o artefato ja existe.
  - Model: `test -f app/Models/<Nome>.php && echo "EXISTE"`
  - Migration: `ls app/database/migrations/*_create_<tabela>_table.php 2>/dev/null`
  - Controller: `test -f app/Http/Controllers/<Nome>.php && echo "EXISTE"`
  - Se existir: NAO recrie. Pergunte ao usuario se deve alterar o existente ou criar com outro nome.
```

### Padrão geral

Mesmo princípio se aplica a outras stacks. Adicionar no `execution.md`:

```markdown
- Antes de criar qualquer artefato (model, migration, controller, componente, view),
  verifique se ele ja existe. Use `find` ou `ls`.
```
