# 1.3 — Brainstorming-Lite (Habilitação no AGENTS.md)

**Categoria:** Tokenomia e Contexto | **Prioridade:** 🔴 Crítica | **Esforço:** M
**Fonte:** DEEPSEEK

> Nota: A skill `brainstorming-lite` em si é criada no item 10.2. Este item (1.3) trata da integração dela no AGENTS.md e no sistema de níveis L1/L2/L3.

## Objetivo

Garantir que o AGENTS.md e o sistema de roteamento usem `brainstorming-lite` para L2 e `brainstorming` completo só para L3.

## Especificação

### Mudança no AGENTS.md

No bloco `## Atalhos de Prompt (/aihub)`:

```markdown
- `/aihub:brainstorm-lite`: Ativa a skill `brainstorming-lite` para tarefas de complexidade L2 (2-5 arquivos).
```

No bloco `> [!IMPORTANT]`:

```markdown
> **DIRETRIZ DE DIÁLOGO E ALINHAMENTO**: Qualquer agente que executar atalhos de planejamento/codificação está proibido de fazer suposições ou criar arquivos em silêncio.
> - **L2 (Padrão):** Use `brainstorming-lite` — 3 perguntas máx, sem spec document.
> - **L3 (Complexo):** Use `brainstorming` completo — spec document + visual companion opcional.
```

### Integração com níveis L1/L2/L3

Ver item 1.5 (`niveis-l1-l2-l3.md`). A triagem é:
- L1 → fast-track (sem brainstorming)
- L2 → brainstorming-lite
- L3 → brainstorming completo

## Arquivos Afetados

- `src/AGENTS.md`: adicionar atalho `/aihub:brainstorm-lite`, atualizar IMPORTANT com distinção L2/L3
