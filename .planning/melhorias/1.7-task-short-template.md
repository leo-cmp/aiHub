# 1.7 — Template task-short.md

**Categoria:** Tokenomia e Contexto | **Prioridade:** 🟢 Média | **Esforço:** S
**Fonte:** ANALISE_FREE.md

## Objetivo

Criar template alternativo de task para tarefas que tocam ≤2 arquivos, sem regra de negócio. 15 linhas em vez das 52 do template completo.

## Situação Atual

`task.md` (52 linhas) tem: frontmatter com 10 campos, Objetivo, Critérios de Aceite, Plano de Execução, Estado Atual, Log de Evidências, Erros e Correções, Não Verificado. Overkill para tarefa de 5 minutos.

## Especificação

### Arquivo: `src/.ai/templates/task-short.md`

```markdown
---
id: TASK-XXX
title: "[Titulo descritivo]"
status: backlog
---

# [Titulo]

## O que fazer
[1-2 linhas]

## Critérios de Aceite
- [ ] Criterio unico (max 2)

## Como verificar
[Comando para testar: ex: `php spark test --group X`]
```

**Quando usar:** Tarefa L1 ou L2 baixa (≤2 arquivos, sem nova regra de negócio, sem schema novo).

**Quando NÃO usar:** Tarefa L3 ou qualquer tarefa com regra de negócio, múltiplos critérios de aceite, ou dependências entre tasks.

### Integração

Adicionar em `planning.md`:

```markdown
- Para tarefas L1, use o template `.ai/templates/task-short.md` (15 linhas).
```

## Arquivos Afetados

- `src/.ai/templates/task-short.md`: NOVO
- `src/.ai/guidelines/core/planning.md`: adicionar referência ao template curto

## Critérios de Aceite

- [ ] `task-short.md` existe com ≤15 linhas
- [ ] Template tem: título, o que fazer (1-2 linhas), critérios (max 2), como verificar
- [ ] Template NÃO tem: Estado Atual, Log de Evidências, Erros e Correções, Não Verificado
- [ ] `planning.md` referencia `task-short.md` para tarefas L1
