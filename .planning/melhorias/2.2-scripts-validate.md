# 2.2 — Script validate.sh

**Categoria:** Robustez do Sistema de Regras | **Prioridade:** 🔴 Crítica | **Esforço:** M
**Fonte:** DEEPSEEK

## Objetivo

Criar script que valida a consistência interna do sistema de regras do aiHub. Detecta: skills referenciadas mas inexistentes, guidelines referenciadas mas inexistentes, links quebrados entre arquivos .md, padrões de contradição.

## Especificação

### Arquivo: `scripts/validate.sh`

```bash
#!/usr/bin/env bash
set -euo pipefail
SRC="${1:-src}"
ERRORS=0

echo "=== aiHub validate ==="

# 1. Skills referenciadas em roles existem?
echo "--- Checking skill references in roles ---"
for role in "$SRC/.ai/roles/"*.md; do
    # Extrai skills listadas no formato "- `nome-da-skill`:"
    grep -oP '(?<=`)[a-z-]+(?=`)' "$role" | while read -r skill; do
        if [ -d "$SRC/.agents/skills/$skill" ]; then
            echo "  OK: $skill (referenced in $(basename "$role"))"
        else
            # Pula falsos positivos (não são nomes de skill)
            case "$skill" in
                brainstorming|brainstorming-lite|caveman|criar-plano|criar-task|\
                executar-task|iniciar-projeto|atualizar-projeto|revisar|\
                laravel-best-practices|tailwindcss-development|daisyui|frontend-design|\
                ci4-best-practices|atualizar-aihub|model-router|project-planner|\
                technical-lead|product-analyst|fullstack-engineer|backend-engineer|\
                frontend-engineer|qa-release-engineer|database-engineer)
                    if [ ! -d "$SRC/.agents/skills/$skill" ]; then
                        echo "  MISSING: $skill referenced in $(basename "$role")"
                        ERRORS=$((ERRORS + 1))
                    fi
                    ;;
            esac
        fi
    done
done

# 2. Guidelines referenciadas existem?
echo "--- Checking guideline references ---"
for file in $(find "$SRC/.ai" -name "*.md"); do
    grep -oP '\.ai/guidelines/[^)\s]+\.md' "$file" | while read -r ref; do
        if [ ! -f "$SRC/$ref" ]; then
            echo "  BROKEN LINK: $ref referenced in $(basename "$file")"
            ERRORS=$((ERRORS + 1))
        fi
    done
done

# 3. AGENTS.md não contém contradições conhecidas
echo "--- Checking for contradictions in AGENTS.md ---"
if grep -q "NUNCA SUPONHA" "$SRC/AGENTS.md" 2>/dev/null; then
    echo "  WARNING: 'NUNCA SUPONHA' found — consider replacing with affirmative instruction"
fi

# 4. Verifica que templates referenciados existem
echo "--- Checking template references ---"
for ref in $(grep -oP '\.ai/templates/[^)\s]+\.md' "$SRC/.ai/guidelines/core/planning.md" 2>/dev/null); do
    if [ -f "$SRC/$ref" ]; then
        echo "  OK: $ref"
    else
        echo "  MISSING: $ref referenced in planning.md"
        ERRORS=$((ERRORS + 1))
    fi
done

# 5. Report
echo "=== $ERRORS errors found ==="
exit $ERRORS
```
