# 6.2 — Máx 3 Tentativas por Critério

**Categoria:** Guardrails Quantitativos | **Prioridade:** 🟡 Alta | **Esforço:** S
**Fonte:** DEEPSEEK

## Objetivo

Detectar loops de falha: se o mesmo critério de aceite falhar 3 vezes consecutivas, pausar e pedir intervenção humana. Após 3 tentativas, a probabilidade de convergência é próxima de zero.

## Especificação

Adicionar ao `execution.md`, após o `## Registro de Evidencias`:

```markdown
## Loop Detection (Circuit Breaker)

Se o mesmo criterio de aceite falhar 3 vezes consecutivas:
1. PARE imediatamente. Nao tente uma quarta abordagem.
2. Registre no Log de Evidencias: as 3 tentativas, o que foi tentado em cada, e o erro.
3. Atualize `.ai/session-memory.md` com o bloqueio.
4. Informe o usuario: "Criterio X falhou 3 vezes. Tentativas: [resumo]. Aguardando orientacao."

Nao continue ate o usuario responder com nova estrategia.
```

### Integração com task.md

Adicionar na seção `## Erros e Correções` do template `task.md`:

```markdown
Se um criterio falhar 3x consecutivas, nao registre como "Erros e Correcoes" —
registre como "BLOQUEIO" e pare.
```

## Arquivos Afetados

- `src/.ai/guidelines/core/execution.md`: adicionar `## Loop Detection`
- `src/.ai/templates/task.md`: adicionar nota sobre bloqueio vs erro
