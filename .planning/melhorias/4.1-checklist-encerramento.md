# 4.1 — Checklist de Encerramento Obrigatório

**Categoria:** Verificação e Anti-Alucinação | **Prioridade:** 🔴 Crítica | **Esforço:** S
**Fonte:** ANALISE_FREE.md

## Objetivo

Adicionar checklist mínimo de encerramento no `execution.md` para impedir "implementei mas não testei". Toda task executável deve passar pelo gate antes de ser marcada como concluída.

## Situação Atual

`execution.md` já tem checklist de PR (linhas 10-15) mas foca em git/PR. Falta um gate simples de qualidade: "roda os testes, olha o diff, confirma que faz sentido."

## Especificação

Adicionar ao final de `execution.md`:

```markdown
## Checklist de Encerramento (Obrigatório)

Antes de marcar qualquer task como concluída, confirme TODOS os itens:

- [ ] Testes relacionados passam (`exit 0`)
- [ ] Lint/formatacão passam (`exit 0`)
- [ ] `git diff --stat` mostra apenas arquivos esperados para esta task
- [ ] `git diff` não contém: comentários de debug, `dd()`, `var_dump()`, `console.log()`
- [ ] Nenhum arquivo de outra task foi alterado acidentalmente
- [ ] Log de Evidências registrado na task (comando + saída + exit code)
- [ ] `plan.md` atualizado com progresso da task
- [ ] `.ai/session-memory.md` atualizado

Se qualquer item falhar, NÃO marque a task como concluída. Corrija e reexecute o checklist.
```

## Arquivos Afetados

- `src/.ai/guidelines/core/execution.md`: adicionar bloco `## Checklist de Encerramento`

## Critérios de Aceite

- [ ] `execution.md` contém checklist de 8 itens
- [ ] Checklist verifica: testes, lint, diff scope, debug artifacts, task isolation, log, plan.md, session-memory
- [ ] Instrução explícita: "Se qualquer item falhar, NÃO marque como concluída"
- [ ] Checklist é referenciado pela skill `executar-task` no passo 6 (concluir)
