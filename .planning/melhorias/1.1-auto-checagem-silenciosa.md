# 1.1 — Auto-Checagem Silenciosa

**Categoria:** Tokenomia e Contexto | **Prioridade:** 🔴 Crítica | **Esforço:** S
**Fonte:** Ambas as análises

## Objetivo

Eliminar o overhead de tokens do Context Canary emitindo "Leo" a cada resposta. Substituir por verificação interna a cada 5 interações, com alerta só quando houver degradação real.

## Situação Atual

```markdown
1. Descubra o nome do usuario via `git config user.name` (fallback: "colega").
2. Comece TODA resposta com o nome do usuario.
```

Problema: cada "Entendido, Leo! Vou verificar..." gasta ~20 tokens de fluff. Em 100 interações, ~2.000 tokens gastos com nome — que aceleram a saturação do contexto.

## Especificação

Substituir o bloco `## Identidade da Sessao (Context Canary)` em `AGENTS.md` por:

```markdown
## Identidade da Sessao (Context Canary)

1. Descubra o nome do usuario via `git config user.name` (fallback: "colega").
2. Use o nome do usuario no inicio da PRIMEIRA resposta da sessao.
3. A cada 5 interacoes, faça uma auto-checagem INTERNA (silenciosa):
   - Ainda sei o nome do usuario?
   - Ainda sei a task atual?
   - Ainda sei a branch atual?
   - Ainda sei o ultimo comando executado?
4. Se 2+ itens falharem, emita no inicio da proxima resposta:
   "[CONTEXT DEGRADED] Sessao atual: <task ou ultimo topico>. Proximo passo: <acao>.
   Considere abrir nova sessao e pedir para continuar de onde parou."
5. Se todos os itens passarem, continue normalmente — sem emitir nada.
6. A cada handoff ou fim de sessao, atualize `.ai/session-memory.md`.
```

## Arquivos Afetados

- `src/AGENTS.md`: substituir bloco `## Identidade da Sessao (Context Canary)`

## Critérios de Aceite

- [ ] AGENTS.md não contém instrução "Comece TODA resposta com o nome do usuario"
- [ ] AGENTS.md contém instrução de auto-checagem silenciosa a cada 5 interações
- [ ] AGENTS.md contém formato do alerta de degradação com task + próximo passo
- [ ] AGENTS.md referencia `.ai/session-memory.md` no handoff
- [ ] Não há referência a "TODA resposta" relacionada ao nome do usuário
