# 6.1 — Máx 5 Skills por Sessão

**Categoria:** Guardrails Quantitativos | **Prioridade:** 🟡 Alta | **Esforço:** S
**Fonte:** DEEPSEEK

## Objetivo

Limitar o número de skills carregadas por sessão. Após 5 skills, o LLM deve reavaliar se precisa de sessão nova. Evita exaustão de contexto por acúmulo de skills.

## Especificação

Adicionar ao `AGENTS.md`, no bloco `## Carregamento de Skills (Lazy Loading)`:

```markdown
**Limite de skills por sessao:** Maximo de 5 skills carregadas. Apos atingir o limite:
- Se a demanda exigir mais skills, considere encerrar a sessao atual e abrir nova.
- Skills como `caveman` (carregada no boot) contam no limite.
- Skills de stack (`laravel-best-practices`, `tailwindcss-development`, etc.) contam individualmente.
```

### Interação com outros circuit breakers

- Caveman (boot) = 1 slot
- Stack skill = 1 slot
- Brainstorming-lite = 1 slot
- Executar-task = 1 slot
- Revisar = 1 slot
- Total máximo = 5

Na prática, uma sessão típica L2 carrega: caveman (1) + stack (1) + brainstorming-lite (1) + executar-task (1) = 4 skills. Sobra 1 slot para eventualidade.

## Arquivos Afetados

- `src/AGENTS.md`: adicionar limite no bloco de Carregamento de Skills

## Critérios de Aceite

- [ ] AGENTS.md especifica máximo de 5 skills por sessão
- [ ] AGENTS.md instrui considerar nova sessão ao atingir limite

- [ ] Skills de stack são contabilizadas individualmente
