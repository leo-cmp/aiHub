# 11.1 — Substituir Makefile por install.sh

**Categoria:** Distribuição e Instalação | **Prioridade:** 🔴 Crítica | **Esforço:** M
**Fonte:** Ambas as análises

## Objetivo

Substituir o Makefile por `scripts/install.sh` — script bash simples para bootstrap do aiHub no projeto alvo. O Makefile é sobre-engenharia (make não é natural pra dev PHP/JS, difícil de debugar, verboso).

## Situação Atual

Makefile (127 linhas) com 12 targets: `install`, `install-force`, `update`, `git-update`, `git-branch`, `git-submit`, `git-push`, `git-pr`, `release`, `check`, `help`. Mistura bootstrap (symlinks) com git operations e release.

## Especificação

### Arquivo: `scripts/install.sh`

```bash
#!/usr/bin/env bash
set -euo pipefail

TARGET="${1:-..}"

echo "=== aiHub install ==="
echo "Target: $TARGET"

# Criar diretórios no projeto alvo
mkdir -p "$TARGET/.ai/guidelines/domain/business-rules"
mkdir -p "$TARGET/.ai/decisions"
mkdir -p "$TARGET/.claude"

# Copiar AGENTS.md como symlink
ln -sfn .aihub/src/AGENTS.md "$TARGET/AGENTS.md"
ln -sfn .aihub/src/AGENTS.md "$TARGET/CLAUDE.md"

# Links simbólicos para roles, guidelines, stacks
ln -sfn ../.aihub/src/.ai/roles "$TARGET/.ai/roles"
ln -sfn ../../.aihub/src/.ai/guidelines/core "$TARGET/.ai/guidelines/core"
ln -sfn ../../.aihub/src/.ai/guidelines/stacks "$TARGET/.ai/guidelines/stacks"

# Skills
ln -sfn ../.agents/skills "$TARGET/.claude/skills"

# Copiar .mcp.json se não existir
if [ ! -f "$TARGET/.mcp.json" ]; then
    cp src/.mcp.json "$TARGET/.mcp.json"
fi

# Criar project.md se não existir
if [ ! -f "$TARGET/.ai/project.md" ]; then
    cat > "$TARGET/.ai/project.md" << 'EOF'
# Novo Projeto

## Ambiente e Estrutura
- **Localização:** Os arquivos rodam diretamente na raiz.
- **Idioma da UI:** pt-BR

## Stack
- Backend: 
- Database: 
EOF
fi

# Criar stack.md se não existir
if [ ! -f "$TARGET/.ai/stack.md" ]; then
    cat > "$TARGET/.ai/stack.md" << 'EOF'
# Stacks do Projeto

Consulte as diretrizes específicas em:
- [Laravel](file:///.ai/guidelines/stacks/laravel.md)
EOF
fi

# Criar session-memory.md se não existir
if [ ! -f "$TARGET/.ai/session-memory.md" ]; then
    cp src/.ai/session-memory.md "$TARGET/.ai/session-memory.md"
fi

# Criar decisions.md se não existir
if [ ! -f "$TARGET/.ai/decisions.md" ]; then
    cp src/.ai/decisions.md "$TARGET/.ai/decisions.md"
fi

# Adicionar .aihub ao .gitignore do projeto alvo
if [ -f "$TARGET/.gitignore" ]; then
    if ! grep -q "^\.aihub" "$TARGET/.gitignore"; then
        printf "\n# aiHub\n.aihub/\n" >> "$TARGET/.gitignore"
    fi
fi

echo "=== aiHub instalado com sucesso ==="
echo "Versão: $(cat VERSION)"
```

### O que NÃO vai no install.sh

Operações de git (`make git-*`) vão para skills ou scripts separados:
- `make git-update` → skill `atualizar-aihub` (item 10.3)
- `make git-branch`, `make git-submit`, `make git-push`, `make git-pr` → Já cobertos por `git-pr.md` guideline. Skills `criar-plano` e `criar-task` já usam `gh`.
- `make release`, `make check` → `scripts/release.sh` e `scripts/check-version.sh` (já existem, não fazem parte do bootstrap)

### Arquivo: `scripts/install-force.sh`

```bash
#!/usr/bin/env bash
set -euo pipefail
TARGET="${1:-..}"
rm -rf "$TARGET/.agents" "$TARGET/.mcp.json"
exec "$(dirname "$0")/install.sh" "$TARGET"
```

### Remover Makefile

```bash
rm Makefile
```

Atualizar `INSTALL.md` para referenciar `./scripts/install.sh` em vez de `make install`.
